# design/

`brand/` holds the vector sources of the BP Transcriber identity: `logo-mark.svg` (UI mark on its own navy disc), `logo-mark-mono.svg` (single-colour gold), `app-icon.svg` (macOS 1024 icon, squircle with the 100 px margin) and `app-icon-windows.svg` (same icon, larger tile, no macOS margin); the four SVGs are generated by `brand/gen_svgs.py` (plain SVG, no filters or rasters; edit the script and re-run it, or edit the SVGs by hand). `ASSETS_BRIEF_FOR_CHATGPT.md` is a self-contained brief (Russian, with English prompts) for producing raster assets with GPT Image; finished files go to `incoming/`, from where they are reviewed and moved to their final places. Rendered icons live in `packaging/icons/` (`bp.icns`, `bp.ico`, `png/icon-<size>.png`); to regenerate them run `python packaging/make_icons.py` (needs `pillow`, `cairosvg`, and on macOS `brew install cairo`; `iconutil` comes with macOS).
